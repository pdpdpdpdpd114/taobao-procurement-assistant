# 车队淘宝采购助手：两分钟安装与使用

## 测试版安装

1. 解压 `taobao-procurement-assistant-0.2.4.zip`。
2. Edge 地址栏输入 `edge://extensions`；Chrome 输入 `chrome://extensions`。
3. 打开右上角“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择解压得到的 `extension` 文件夹。
5. 登录淘宝并打开确认订单页面，右侧出现“核对采购申请”按钮即安装完成。长截图会重复拼接固定按钮；若实际浏览器中也有多个按钮，再检查是否同时安装了旧版扩展。

> 正式团队版发布到 Edge Add-ons Hidden 渠道后，队员只需打开管理员提供的专属链接安装，不需要开发人员模式，并可自动更新。

## 第一次使用

1. 在淘宝购物车勾选本次需要采购的商品，插件读取后会自动保存本机草稿；正常进入确认订单页即可，无需先在购物车启动插件。
2. 点击页面右侧“生成采购申请”。
3. 首次使用填写部门、申请人、采购人、组长、队长/副队长和负责老师。
4. 在淘宝“确认订单”页点击“核对采购申请”，逐项核对商品简称、型号和每条购买数量。
5. 按确认订单页核对单价、店铺运费、优惠和应付金额。自动识别不全时可手动填写，并点击“我已逐项核对当前页面”。
6. 采购时间必须填写；发票日期、制作成品、用途、库存情况、使用/保管人、到货日期及三项预算均可留空。预算如填写任一项，三项都要填写。
7. 点击“校验并下载Word”。校验通过后，文件会下载到浏览器默认下载目录。

## 管理员配置

- 管理员将 `team-config.example.json` 复制为团队配置，维护部门、人员、预算和模板版本。
- 队员在插件中导入该 JSON；个人档案、配置和草稿只保存在本机浏览器。
- 发布新版本时提升插件版本号，并保留配置迁移逻辑。

## 注意事项

- 购物车页面价格不等于确认订单页的最终结算价格；插件仅在确认订单页允许导出。
- 跨店优惠、最终运费或价格不明确时必须人工确认，插件不会静默按零处理。多店铺运费无法归属时需逐项填写。
- 确认订单页商品件数、明细金额、运费、优惠和应付金额必须核对；购物车快照不再是导出前提。
- 导出前如果购物车选中数量与解析数量不一致、模板损坏或必填项缺失，插件会阻止导出并说明原因。
- 遇到读取失败，可点击“导出脱敏诊断”，由队员自行发送给管理员；插件不会自动上传。

## 清除与恢复

- “导出本地数据”可备份个人档案、团队配置和草稿。
- “恢复本地数据”可从备份 JSON 恢复。
- “清除本地数据”会删除本浏览器中的所有插件数据，请先确认是否需要备份。
